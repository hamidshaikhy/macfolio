# گزارش بررسی پروژه

## آزمون‌های خودکار

```bash
npm test
```

نتیجهٔ نسخهٔ منتشرشده: **۳۸ تست موفق، صفر شکست**.

| فایل | تعداد | پوشش |
| :--- | ---: | :--- |
| `tests/finance.test.ts` | ۱۸ | مبلغ، رقم‌ها، تراز، انتقال، تاریخ جلالی، بودجه، تکرار، CSV و دمو |
| `tests/security.test.ts` | ۱۴ | حساب‌های جدا، رمز، دستکاری ciphertext، persistence، تب قدیمی، پشتیبان و ارتقای دمو |
| `tests/render.test.ts` | ۳ | نمودار، فرم‌های شش موجودیت و وضعیت خالی |
| `tests/flow.test.ts` | ۳ | حفظ مجموع مسیرها، مقیاس مشترک، فاصله و هندسهٔ خالی |

تست امنیت از Web Crypto واقعی Node و `fake-indexeddb` استفاده می‌کند؛ ممیزی مستقل امنیت یا آزمون نفوذ نیست.

## TypeScript و ساخت

`npm run build` شامل `tsc -b`، Vite و ساخت service worker است و موفق شد. `node_modules/`، `dist/` و فایل‌های تولیدی TypeScript در Git قرار نمی‌گیرند.

## بررسی مرورگر

`npm run capture:screenshots` سیزده تصویر ثبت می‌کند و این موارد را بررسی می‌کند:

- ورود با دمو در دو context مستقل.
- تفاوت ارتفاع شش ستون درآمد و شش ستون هزینه.
- بازشدن صفحه‌های گزارش، حساب، بودجه، برنامه‌ریزی، تراکنش و تنظیمات.
- بازشدن فرم ثبت و نمودار فشردهٔ موبایل.
- نبود اسکرول افقی و خطای اجرایی صفحه در نماهای ثبت‌شده.

مشخصات محیط در [screenshots/capture.json](screenshots/capture.json) است. همهٔ داده‌ها نمایشی و تاریخ ثابت است.

در بررسی قبلی، عرض‌های ۳۲۰، ۳۹۰، ۶۴۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰، hover سنکی، جزئیات موبایل و ارتقای نسخهٔ اصلی دموی ذخیره‌شده نیز بررسی شدند.

## بررسی‌های دستی باقی‌مانده

Safari، Firefox، گوشی واقعی iPhone/Android، کیبورد و دانلود گوشی، نصب وب‌اپ، بازگشت آفلاین و محدودیت واقعی storage باید جداگانه بررسی شوند. نمای موبایل مرورگر جای آزمون دستگاه واقعی را نمی‌گیرد؛ نتیجه‌ای برای بررسی انجام‌نشده ادعا نشده است.
