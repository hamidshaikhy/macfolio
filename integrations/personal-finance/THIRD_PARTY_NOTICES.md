# اعتبار و مجوز وابستگی‌ها

برای کد اصلی هنوز مجوز عمومی مستقلی انتخاب نشده و فایل `LICENSE` وجود ندارد. این جدول مجوز وابستگی‌هاست، نه مجوز کد اصلی.

| بسته یا دارایی | کاربرد | مجوز | متن مجوز |
| :--- | :--- | :--- | :--- |
| React / React DOM | رابط و رندر | MIT | [React](docs/licenses/react.txt)، [React DOM](docs/licenses/react-dom.txt) |
| Lucide React | آیکن‌ها | ISC؛ بخش‌های Feather تحت MIT | [Lucide](docs/licenses/lucide-react.txt) |
| idb | wrapper برای IndexedDB | ISC | [idb](docs/licenses/idb.txt) |
| jalaali-js | تقویم جلالی | MIT | [jalaali-js](docs/licenses/jalaali-js.txt) |
| Vazirmatn | فونت فارسی همراه `@fontsource/vazirmatn` | SIL Open Font License 1.1 | [Vazirmatn](public/licenses/Vazirmatn-OFL.txt) |

متن‌ها از بسته‌های نصب‌شده کپی شده‌اند و اعلان‌های copyright آن‌ها حفظ شده‌اند. نسخه‌ها در `package-lock.json` هستند. ابزارهای توسعه نیز مجوز خود را در بسته نگه می‌دارند؛ Playwright، ابزار ثبت تصاویر، مجوز Apache-2.0 دارد.

تمام تصاویر گالری از همین برنامه با دادهٔ دمو ثبت شده‌اند و دفتر مالی واقعی، عکس stock یا تصویر تولیدشده با مدل تصویر را شامل نمی‌شوند.

تراکم اطلاعات نمای کلی از ایدهٔ داشبوردهای مالی مانند Syllogic الهام گرفته است. پیاده‌سازی رابط، نمودار، مدل و ذخیره‌سازی متعلق به این پروژه است. README پروژهٔ Flow Studioِ همین نویسنده مرجع سبک ارائهٔ مستندات بوده است.
